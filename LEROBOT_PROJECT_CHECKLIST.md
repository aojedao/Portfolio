## 💡 Tips

### For Images:
- Extract key frames from demonstration videos
- Show before/after comparisons
- Include robot's perspective (camera view)
- Capture grasp points and trajectories
- Show successful and challenging cases

### For Metrics:
- Be specific with numbers (e.g., "87% success rate" not "high success")
- Include error bars or confidence intervals
- Compare across different conditions
- Show learning curves if available

### For Technical Details:
- Include hyperparameters used
- Mention training time and hardware
- Document any special techniques
- Note failure modes and limitations

### For Diagrams:
- Use clear, professional-looking diagrams
- Label all components
- Show data flow direction
- Use consistent color schemes
- Export as PNG with transparent background
