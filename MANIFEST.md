### Zero-Setup Option
```bash

# → llm_prompt.txt (copy to ChatGPT)
```

### With OpenAI API
```bash
python project_processor.py "your-project" \
  --output "project.md" \
  --api_key "sk-..." \
  --use-llm
# → project.md (complete markdown)
```
