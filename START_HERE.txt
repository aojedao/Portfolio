## QUICK START (2 MINUTES)

Step 1: Create Project Folder
────────────────────────────
my-project/
├── report.txt         ← Your project description
├── images/            ← Photos (JPG, PNG)
├── models/            ← 3D files (GLTF, STL)
└── schematics/        ← Diagrams (SVG, PDF)

Step 2: Run Processor
────────────────────
cd scripts
python project_processor.py "path/to/my-project"

Step 3: Get Markdown
────────────────────
Option A (Free - Manual):
  - Copy llm_prompt.txt
  - Paste into ChatGPT/Claude/Gemini
  - Copy response → Save as project.md

Option B (Automated - Needs API):
  - Get API key from https://platform.openai.com/api-keys
  - Run: python project_processor.py "project" \
         --output "project.md" --api_key "sk-..." --use-llm
  - project.md created automatically

## HOW IT WORKS

Your Project Folder
        ↓
Project Processor
├─ Scans files
├─ Reads report
├─ Detects language
└─ Generates prompt
        ↓
LLMContextGenerator
├─ Creates comprehensive prompt
├─ Embeds file references
├─ Formats for MESGRO template
└─ Exports JSON context
        ↓
   Output Files
├─ llm_prompt.txt (for manual LLM)
├─ project_context.json (metadata)
└─ project.md (if using API)
        ↓
    Your Markdown
  Ready for GitHub
   & MESGRO Site
