## Image Guidelines

- **Format**: JPG for photos, PNG for diagrams/charts, MP4 for videos
- **Resolution**: Minimum 1920x1080 for main images
- **Aspect Ratio**: 16:9 preferred for gallery images
- **File Size**: Keep under 2MB per image for web optimization
- **Naming**: Use lowercase with hyphens (e.g., `shorts-folding-step1.jpg`)
